# Todo List – React + TypeScript + Vite

A minimal, clean Todo List application built with **React**, **TypeScript**, and **Vite**. It showcases light/dark theming, adding, editing, completing, and deleting tasks, plus responsive design for desktop and mobile.

## How to start it

```bash
# Install dependencies (npm or yarn)
npm install   # or: yarn

# Run the development server
npm run dev   # or: yarn dev

# Build for production
npm run build # or: yarn build
```

The app will be available at `http://localhost:5173` (or the port shown in the console).
